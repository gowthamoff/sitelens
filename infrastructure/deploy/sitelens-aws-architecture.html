Request flow

  1. Frontend: user → CloudFront → S3 (cached).
  2. API: user → CloudFront → FastAPI on EC2 → RDS PostGIS → JSON.
  3. Tiles (12M pts): FastAPI ST_AsMVT → CloudFront caches → map. Raw points never leave the DB.
  4. Deploy: push to GitHub → on EC2 git pull → docker build → docker run.
